# Public post-seal evidence bundle

This directory is the reviewable evidence bundle for the author-amended n=11
fresh q256 crossed-switch replication. The files were copied from the formal
MatPool node only after the recovery evaluation matrix reached 242/242
`SEALED_PASS` and `evaluation_matrix_seal.json` reached `SEALED_PASS`.

## Verdict

The frozen primary verdict is **INCONCLUSIVE**:

- H mean: -0.0755664012;
- two-sided 95% CI: [-0.155323, 0.00419019794];
- TOST two-sided 90% CI: [-0.140443747, -0.0106890552];
- negative seed-level directions: 8/11;
- exact two-sided sign-flip p: 0.0419921875.

The 95% interval covers zero, so directional replication was not confirmed. The
90% interval is not wholly inside the frozen +/-log(1.03) equivalence band, so a
practical null was not established either. Descriptive diagnostics cannot alter
this primary classification.

## Contents and provenance

`SHA256SUMS_11SEED.txt` is the unmodified formal-node manifest generated by the
finalizer. All 18 entries were rehashed after download and matched. It contains
absolute formal-node paths because changing those lines would destroy the
original finalization artifact.

`PUBLIC_SHA256SUMS.txt` binds every file committed in this directory using local
filenames and can be checked from this directory with:

```bash
sha256sum --check PUBLIC_SHA256SUMS.txt
```

The bundle contains the final report and receipt, authorizations, public opaque
manifest, integrity and matrix seals, decoded post-seal results, frozen
statistics, per-seed contrasts, compute ledger, and seed38 failure evidence.

`REMOTE_TEST_RECORD.md` and the two `remote_test_31b127e_*.log` files bind the
29 original tests and 14 remediation tests to source commit `31b127e`, the
frozen runtime-manifest SHA, and the exact commands executed on the formal node.

The bundle deliberately excludes:

- `sealed_private_evaluation_map_11seed_recovery1.json` and every archived private map;
- all P2 content;
- checkpoints, generated features, and temporary `metric-*.jsonl` files;
- credentials or authentication material.

Public authorization and seal files retain hashes and formal-node paths for the
private map. Those values are commitments to the unseen map, not the map content
or a seed/cell lookup table.

## Seed38 missingness

See `SEED38_FAILURE_CLASSIFICATION.md`. The published training log, telemetry,
monitor log, and terminal compute receipt show one protocol-managed overflow at
attempt 4857, continued finite training through attempt 4865, and a second
non-finite loss at attempt 4866 that correctly failed closed. Because this
occurred in the AB treatment trajectory, complete-case exclusion may be
informative and is not described as ordinary random infrastructure loss.

## Interpretation boundary

Execution integrity is `PASS`; scientific confirmation is not. The defensible
paper narrative is discovery evidence at seeds3--7 followed by an outcome-blind,
author-amended n=11 complete-case replication with an inconclusive primary
result and a trajectory-specific missingness limitation.
