# q, g, and effective pair spacing

**Status:** one-page theory note for PR #81. It defines a future matched-spacing
control but does **not** authorize a training run.

## Claim boundary

We have not shown an effect of $g$ independent of $q$. The current experiment
holds $q=256$ fixed and uses $g=1.10$ as a controlled probe of the realized
pair spacing. The scientific object is the pair-spacing intervention: in ECT,
changing spacing simultaneously moves the detached target endpoint and changes
the explicit loss weight.

## Exact relation in the current implementation

At curriculum stage $j$, let $n(t)=1+k\sigma(-bt)$. The repository constructs

$$
r_q(t,j)=\max\left\{0,t\left(1-\frac{n(t)}{q^{j+1}}\right)\right\},
\qquad
\Delta_q(t,j)=t-r_q(t,j),
$$

and the global probe applies

$$
\Delta_{q,g}(t,j)=\min\{t,g\Delta_q(t,j)\},
\qquad r_{q,g}(t,j)=t-\Delta_{q,g}(t,j).
$$

Let $(q_0,g_0)$ denote the reference parameters. At a fixed stage and away
from clipping, the same pair is generated by the alternative parameters

$$
q_{\mathrm{eff}}(j)=\frac{q_0}{g_0^{1/(j+1)}},
\qquad g'=1.
$$

The formal protocol has $q=256$, $k=8$, $b=1$, $g=1.10$, 10 kimg per tick,
and \texttt{double\_ticks}=10000, so the full 1024-kimg horizon remains at
$j=0$. For $t>0$, $n(t)=1+8\sigma(-t)\leq5$, hence
$g n(t)/q\leq5.5/256<1$ and neither rule clips. Therefore, pointwise in every
realized $t$,

$$
\boxed{\Delta_{256,1.10}(t,0)=\Delta_{256/1.10,1}(t,0)},
\qquad q^\star=256/1.10\approx232.727.
$$

Thus $g=1.10$ is exactly a stage-0 pair-construction reparameterization in real
arithmetic, not evidence for an independent $g$ mechanism. More generally,
effective pair spacing is the joint law
$\mathcal P_{q,g}=\operatorname{Law}(J,T,\Delta_{q,g}(T,J))$ under the frozen
curriculum and time sampler; it is not the mean gap or either nominal scalar.

The merged q128 matched-spacing arm obeys the same stage-0 identity:
$0.55/128=1.10/256$. Its within-cohort five-arm contrasts remain valid. A
comparison between that arm and the historical q256 enlarged-spacing run,
however, compares different executions, source revisions, hardware assignments,
AMP histories, and stochastic trajectories. Their quality difference therefore
does not identify an independent effect of nominal $q$.

For the ECT loss

$$
\ell(\theta;t,r)=\frac{1}{t-r}\,
d\!\left(f_\theta(x_t,t),\operatorname{sg}[f_\theta(x_r,r)]\right),
$$

a spacing change alters both $r$ inside the detached target and the explicit
factor $1/(t-r)$. PR #81 factorizes those two changes at a common state; it
does not factorize $q$ and $g$ as independent causes.

## Future effective-spacing-matched control

**Reference path G:** freeze one source revision and run exactly
`--mapping global_sigmoid --factorial-protocol none -q 256
--global-gap-scale 1.10`.

**Matched path Q:** at the same frozen source revision, run exactly
`--mapping global_sigmoid --factorial-protocol none
-q 232.72727272727272 --global-gap-scale 1`. Thus $g'=1$ and
$q^\star=q_0/g_0$ for this stage-0 protocol. The CLI and schedule constructor
must preserve this floating-point $q^\star$ in the signed launch manifest.
For a future multi-stage audit, exact matching instead requires
$q_j^\star=q_0/g_0^{1/(j+1)}$ at each stage; one fixed $q'$ generally cannot
match every stage.

Both paths must share the stage sequence, sampled $t$, data order, noise,
augmentation/dropout RNG, online parameters, target/denominator assignment,
AMP, optimizer, EMA, and evaluation code. Before any training, a frozen
$t\times j$ grid and paired production minibatches must pass all four gates:

1. realized $r$, $\Delta$, and clipping indicators agree pointwise;
2. target inputs and explicit weights agree;
3. per-sample losses and one-sided SG fields agree under shared RNG; and
4. nominal $q$ and $g$ enter no unmatched model, sampler, controller, optimizer,
   EMA, or loss path.

Freeze tolerances in advance; a suitable pair-coordinate gate is

$$
\max_i\frac{|\Delta_i^G-\Delta_i^Q|}{\max(1,|t_i|)}
\leq32\epsilon_{\mathrm{FP32}},
$$

with relative whole-field error below $10^{-6}$. Report the maximum pair,
loss, and field errors plus every unmatched code path. Failure diagnoses an
implementation or numerical mismatch. Passing the gates supports classifying
the audit as an implementation-equivalence diagnostic; it is not run
authorization and does not prove bitwise identity at every future update. If
training is separately authorized later, its primary estimand must therefore be
paired parameter/EMA trajectory equivalence under a frozen equivalence margin,
not FID/KID superiority or an independent $g$ mechanism.

**Current decision:** do not start full training. A separately frozen, low-cost
production parity audit now evaluates the schedule grid, target tensors, explicit
weights, losses, and one-sided gradients at a common checkpoint; see
`analysis/Q_G_PRODUCTION_PARITY_AUDIT_PROTOCOL.md`.
