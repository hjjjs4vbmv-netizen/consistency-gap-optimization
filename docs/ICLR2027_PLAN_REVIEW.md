# ICLR 2027 方案对抗性审查 — GFCT(Role C)

日期:2026-08-10。由 6 个对抗辩位 + 1 个裁判构成的多智能体审查(见 memory
`iclr2027-gfct-strategy`)。审查对象:`docs/ICLR2027_STRATEGY.tex` 的 E1-E12 实验
方案。核心问题:**这套方案能否实现"化腐朽为神奇"——即真正把当前失败的项目转化为
强 ICLR 2027 投稿?**

---

## 0. 结论摘要(mean 版)

**裁判定论:不能真正"化腐朽为神奇"。** 方案能把诚实的负结果救成一个稍好一点的
*诊断论文*,但**不是机制+方法**。40-50% 的提升整个押在一个未经测试、且自相矛盾的
假设上:去掉非标量残差(Arm C)能胜过未修正臂(Arm U)。所有证据都指向反方向。

6 个辩位:1 个"can deliver"、4 个"partially delivers"、1 个"cannot deliver"。
5 个辩位把"最不确定环节"指向同一个实验:**E2(因果干预)**。

---

## 1. 六个辩位

### 辩位 1 —— 乐观派:can deliver
方案把项目唯一的真实资产(实测 ~3.2% per-step 非标量残差,1.001 vs 0.837)从
"未解释的相关"(弱)重构成"带可修修复的因果机制"(强)。3.2% 是承重数字:每步
约 3.2% 的离轴误差在 ~100k 步上乘性复合,正好把 1.001 变成 0.837——残差不是
噪声,正是先前看似 null 的那个 gap 的原因。反转论文主线在科学上是成立的,不是
spin。E2 门控在阶段一、且便宜(CIFAR-10/256-kimg 在单 GPU 上不贵),失败会被
早期且廉价地发现。

### 辩位 2 —— 方法怀疑派:partially delivers
机制腿(E1/E5/E6/E7)能确立残差存在且有结构,但**方法腿(E2/E8/E9/E10)会崩**:
非标量残差本质是"更新不是某个参考方向的标量倍数",即更新各向异性。而
AdaGrad/Adam/Muon 存在的全部理由就是梯度各向异性。把梯度投影到标量参考方向,
等于把优化器标量化,可能扔掉真实信号。**没有理论理由认为各向异性有害,反而有
强理由预期相反。**

### 辩位 3 —— 过度工程派:partially delivers
整个"机制+方法"升级坍缩成一个昂贵的因果实验(E2)+ 一个便宜的门控分析(E5)。
E1 是现有 arm_{a,b,c} 状态的免费事后读。承重核心是:分析已有的(E1/E5)、跑唯一
决定性干预(E2)、围绕它写论文。12 个实验在 1 张 GPU 上纯属表演。

### 辩位 4 —— 前提怀疑派:cannot deliver
"梯度在深层网络里不是全局标量"对自适应优化器文献是**显然的**——这正是我们有
逐坐标优化器的原因。所以"训练干预不完全等价于标量学习率改变,因为梯度有结构"
可能是真的,但对 ICLR 审稿人是平凡的。CIFAR-10-only、过时范式、负结果、晚进,
再多实验打磨也过不了 significance 关。诚实的答案是放弃/转向/投 workshop。

### 辩位 5 —— mean ICLR 审稿人:partially delivers
反转是对的,诚实的负结果是唯一可辩护的资产(非标量残差内容在 2025-26 标量
scale-invariance 线上确实未被占据)。但"化腐朽为神奇"要求机制+方法声明是真的,
而它不是,原因有三:(1) 方法腿被"换优化器"混杂(投影到 G_1 标量化了更新);
(2) 自己数据里 g=1.3(带残差)已赢 FID;(3) E12 中介在 ~3 次训练上统计上必死。

### 辩位 6 —— 可行性审查:partially delivers
计算上崩:约 6-8 周单 GPU 预算被 E2+E6+E9+E10 耗尽,E3/E4/E11-full 根本跑不了。
可行核心:分析(E1/E5/E7/E8/E12,近零 GPU)+ 单个优先级的 E2 训练。E5→E2 的门控
正是最可能被先砍的 GPU 关键路径。

## 2. 裁判的四个核心判断

### 2.1 机制能立吗?
**能确立残差存在且有结构,但立不起"是原因"。** E1/E5/E6/E7 便宜且能合法展示:
~3.2% 残差非标量、可复现、可按层/幅值/方向分解。但残差→FID/不稳定的因果链
被方案自己的 corr≈0 头条、以及 g=1.3 赢 FID 的事实**直接反驳**。
E1 的门控前提("残差预测 FID/不稳定")可能自己就过不了门——现有审计已测得
~零相关。残差→有害信号出现的可能性:**低,约 15-25%**。

### 2.2 方法能立吗?
**低,这是方案最弱的地方。** E2 要求 ~3.2% 的各向异性分量去推动 CIFAR-10 FID
越过 ~0.1-0.3 的 seed 噪声,先验还是 corr≈0,而且干预本身去掉了逐坐标
preconditioning——合理结果是 Arm C ≈ Arm U 或 Arm C < Arm U。即使 Arm C 为正,
也被混杂:投影+重缩放改变了有效步长,所以 Arm C ≈ 隐式降学习率,E10 基线无法
干净分离"残差被移除"与"优化器被改变"。**E2 干净且无混杂地证明残差特定改善的
现实概率:约 10-20%。**

### 2.3 现实概率
- 坚持"机制+方法 40-50%" → 实际 **10-15%**(前提被自己数据推翻)
- 收缩成诚实诊断(非标量梯度内容的结构刻画)→ **20-30%**
- 净现实区间:**15-30%**,中心约 20-25%。方案能把负结果从死胡同救出来,
  但**造不出机制+方法框架所要求的 significance**。

### 2.4 单一最重要动作
**在设计 E2 之前,先在现有数据里判明"残差到底有没有害"。** 具体:
1. 严格推导 3.2%-norm → 16%-h-shift 的归因(1.001→0.837)——复合/方向集中/重推导;
2. 预注册一个带残差那臂真正退化的指标(NFE=1、diversity/mode collapse、
   run-to-run 稳定性方差),并调和它与 g=1.3-赢-FID 的矛盾;
3. **若找不到任何残差导致退化的指标,机制+方法前提已死,E2 一天 GPU 都不值。**

---

## 3. 致命证伪条件(出现即方案死亡)

- E1/E5 在所有状态和 seed 上 corr≈0 持续(无残差→FID/不稳定信号)
- E5 返回"残差是每步噪声,无层/幅值/方向结构"(无修复方向 → Arm C 无可纠正)
- E2 只能通过标量化优化器来改善(投影到 G_1 去掉了 preconditioning,不只是残差)
- 自己数据里 g=1.3 已在头号 FID 指标上赢过 g=1.0("残差损质量"被反驳)
- 3.2%→16% 归因无法被任何复合/方向论证推导出来(反转主线建在未解释数字上)
- E12 中介检验力不足(约 3 次训练;跨 checkpoint 伪重复自相关,伪造置信区间)
- 找不到带残差那臂退化的任何指标,且 E3/E4 无法把修复迁移到第二 optimizer

---

## 4. 修订后的方案(裁判建议)

**第一阶段(第 1-3 周,近零 GPU):在现有 arm_a/b/c 上跑免费分析。**
- E1 跨状态残差、E5 结构分解、E7 优化器状态依赖;
- **把 E5 当作硬性 GO/NO-GO**。若残差是每步噪声或无残差→退化信号,
  正式放弃方法腿,收缩为诚实负结果诊断论文,**不在 E2 上花一天 GPU**。

**先严格推导 3.2%→16% 归因**,再写任何因果声明。推不出来 → 反转主线是沙上之塔,
机制声明必须放弃。

**预注册带残差那臂的退化指标**(NFE=1、diversity/mode collapse、run-to-run 方差),
并调和 g=1.3-赢-FID。找不到该指标 → "残差损质量"前提被自己数据证伪,机制死亡。

**重设计 E2,隔离残差而不标量化优化器**:只移除参考方向的残差分量、保留逐坐标
自适应缩放,加"冻结方向、保留自适应"对照。若修复的唯一方式是投影到标量参考,
则放弃方法声明,把结果报告为"诊断 + 设计启示",而非"修复"。

**砍掉 E3(ImageNet-64/DiT)和 E4(完整 MeanFlow)** 的可运行部分,降为未来工作/
limitation 文本;最多保留一次便宜的 AdamW 跑作 E3-lite 普适性。

**重新为 E12 供电**:需要 ≥20-30 次独立训练跑遍 gap sweep,或用扰动/工具变量
识别替代中介;绝不用跨 checkpoint 样本作 bootstrap 重复(~3 次的版本在 CIFAR-10
上统计上无意义)。

**E11 收缩为只对赢臂做 2-3 个 seed**;E6 剂量响应塌缩为未被覆盖的 gap(如加
g=1.5);E9 的 alpha 网格收缩到 ~3 个点,都严格门控在 E2 成功之后,以保护单 GPU 预算。

**重新定位论文**:以可辩护的诊断领衔——"标量 moment-memory 理论被证伪;few-step
一致性训练带有结构化的非标量梯度内容"——把 Arm C 作为一次探索性消融、残差到 gap
的归因作为设计启示,目标是 workshop/benchmark track,或在更大的 MeanFlow 投稿内
作为子结果。这保住了 ~可发表的诚实负结果(20-30%),而不是过度声称一个被 corr≈0
头条和 g=1.3-赢 数据已经破坏的机制+方法。

| 先前战略 | 本次审查修正 |

## 6. 实测判定(2026-08-10,决定性实验后追加)

审查 §2.4 的"单一最重要动作"——判明残差是否有害——现已用实测数据执行并得到
决定性结论(实验细节见 `analysis/g13_vs_g10_fid_result.md`)。

**实验:** 在残差被测的同一批状态(`gap_lr_matched_q128_s3_v1` 的 arm_a $g=1.0$ vs.
arm_b $g=1.3$,两者 `global_sigmoid`、lr 固定 1e-4、256 kimg)上,评估 FID-5k/KID-5k
(NFE=1 与 NFE=2,3 次重复)。

**结果($g=1.3$ 相对 $g=1.0$):**
- FID-5k:NFE1 $208.1$ vs.\ $315.8$($-34.1\%$);NFE2 $56.6$ vs.\ $87.7$($-35.5\%$)
- KID-5k:NFE1 $-37.4\%$;NFE2 $-44.7\%$

**结论:** 带非标量残差的臂(g=1.3)在两级 NFE、两个指标上**全面大幅胜出**。这
把审查中"g=1.3 赢 FID 只是声称、仓库里没有实测"的缺口补上——**现在实测了,而且
强烈成立**。

**对方案的决定性影响:**
1. **"残差有害"前提被实测证伪。** 带残差的臂质量更好,未找到任何残差导致退化的指标。
2. **E2 因果干预被反指。** Arm C(投影回 g=1.0 方向)会向更差的 FID 移动。
   E2 降级为"探索性消融 / 设计启示",不作为论文主结果。
3. **论文必须收缩为诚实诊断**(约 20-30%):非标量残差存在、有结构、无害,且
   标量 moment-memory null 被证伪(预测 1.001 vs 实测 0.837)。
4. **"机制+方法 40-50%"被正式放弃。**

**注意:** g=1.3 与 g=1.0 差的是整个 gap(标量+非标量分量),故不能断言残差本身
导致质量提升;但关键点已定——残差无害,带它的臂更好。
