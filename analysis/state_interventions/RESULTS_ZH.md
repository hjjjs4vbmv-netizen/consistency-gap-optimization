# M2 重启时刻与双向 optimizer 互换：六 seed 结果

## 结果摘要

本轮在原 M1 四臂均完成的六个 seed（55、56、59、60、61、62）上完成24条新训练、216项新增评估，并引用120项原1024-kimg评估。这里的“完成／PASS”指运行和指标有效，**不是实验假设获得支持**。

M2 的主要共同终点时间对比为 **1.6531 log-FID，95%名义区间 [-0.2891, 3.5952]，INCONCLUSIVE**。不能据此确认晚期重启改变了 A/B 历史的相对损伤，更不能说晚期重启更安全。绝对质量显示多条晚期重启轨迹严重变差，但仍产生有限、有效的指标，全部保留。

SWAP 的两个预设来源对比为 **D_A=-0.02596、D_B=-0.01531 log-FID**，两项区间均跨0。点估计均倾向 B 来源 optimizer，但既未解析为两个接收方共有的优势，也未解析为自身来源配对的优势。不会合并成一个“SWAP成功”判定。

上述样本是已观察的完成条件子集，不是独立复制，也不代表原16/30-seed无条件总体。区间跨0不是等效性证据；本轮不改变原M1结论。

## 对象、缩写和指标

| 名称 | 含义 |
| --- | --- |
| A／B 历史 | 0–512 kimg 的 target/denominator scale 分别为(1.0,1.0)与(1.1,1.1)；512后统一采用A |
| K_A、K_B | 保留相应历史模型及 optimizer，正常续训的原对照；不是另一个新实验 |
| R_A、R_B | 原M1在512 kimg清空完整RAdam状态后续训 |
| L_A、L_B | 本轮从原K@768恢复，在768 kimg清空完整RAdam状态，训至1024 |

| ONLINE | 终点在线模型权重，不做EMA平均 |
| E_KEEP | 延续接收方原EMA（指数移动平均） |

| kimg／attempt | 累计千张训练样本／尝试更新次数；1024 kimg=8000 attempts，不等同于8000次成功更新 |
| NFE1 | 每个生成样本使用一次模型评估；所有质量比较均保持NFE1、FP32 |
| FID50k | 50,000个生成样本与真实数据在特征空间中均值、协方差差异的Fréchet距离；越低越好，不是百分比 |
| KID50k | 同批特征的核两样本差异估计；越低越好，使用原始数值、不取log、不乘1000；估计量可为负 |
| B0／B1／B2 | 样本seed范围0–49999／50000–99999／100000–149999；是同checkpoint重复生成，不是新训练seed |
| SD／95% CI | 六个配对seed差值的样本标准差(ddof=1)／双侧95% Student-t名义置信区间 |

主读出使用 `ell_s(X,T)=mean_b ln(FID_s,X,T,E_512,b)`。先对每个block取自然对数再平均，不是`ln(mean FID)`，也不是FID150k。一个seed的三个block仍只贡献一个配对观测，主比较n=6而非18。KID先在同seed三个block上平均原值，再计算差值。

冻结评估器为 `d6aba02fb88e9db0993623895eb2228ed717d810`，metric RNG=20260730。FID/KID共享生成特征，KID不是独立验证。新评估使用评估ZIP；旧指标保留其实际训练ZIP来源，两包50,000张图及dataset.json的解压内容已逐项核对一致。没有改写旧记录。

## M2：相对时间差未解析，晚期完整重启本身并不温和

对历史h，`d_h^512(T)=ell(R_h,T)-ell(K_h,T)`，`d_h^768(1024)=ell(L_h,1024)-ell(K_h,1024)`。正值表示重启后FID更差。历史损伤差`J=d_B-d_A`。

唯一主要时间量为共同1024终点：

`Theta_SE=J^768(1024)-J^512(1024)=(L_B-L_A)-(R_B-R_A)`。

同终点K在Theta中代数抵消，但以下A/B损伤都保留K，且同一六seed集合重算。

| A：512重启损伤 d_A^512(1024) | 1.63959 | 1.14906 | [0.43373, 2.84546] |
| B：512重启损伤 d_B^512(1024) | 0.63419 | 1.03797 | [-0.45510, 1.72348] |
| A：768重启损伤 d_A^768(1024) | 2.36761 | 1.32100 | [0.98130, 3.75392] |
| B：768重启损伤 d_B^768(1024) | 3.01527 | 1.43360 | [1.51080, 4.51973] |
| A侧时间变化 T_A | 0.72802 | 1.57330 | [-0.92306, 2.37909] |
| B侧时间变化 T_B | 2.38108 | 1.66454 | [0.63425, 4.12790] |

| 辅助 Theta_SC | 1.54228 | 2.11349 | [-0.67570, 3.76025] |

同样重启后训练256 kimg的辅助量是`Theta_SC=J^768(1024)-J^512(768)`。其晚期损伤仍以K@1024为分母，不偷换成K@768。SE、SC及交集集合均为同六seed，没有集合变化；两种口径的区间均跨0。B侧T_B的单项区间在0以上，不等于A/B时间变化的差Theta已经解析。

## SWAP：来源点估计偏B，主FID仍未解析

在共同1024终点，`D_A=ell(X_A_from_B)-ell(K_A)`，`D_B=ell(K_B)-ell(X_B_from_A)`。**D_B的符号尤其重要：不是X_B_from_A−K_B。** 两者统一为B来源相对A来源，负值表示B来源更有利。

| 主要E_512三block | mean log-FID差 | SD | 95%名义CI | exp(mean)-1 |
| --- | ---: | ---: | --- | ---: |
| A接收方 D_A | -0.0259614 | 0.0285564 | [-0.0559294, 0.00400669] | 约-2.56% |
| B接收方 D_B | -0.0153145 | 0.0371280 | [-0.0542779, 0.0236490] | 约-1.52% |
| 辅助匹配代价 P_match=(D_A-D_B)/2 | -0.00532345 | 0.0137386 | [-0.0197413, 0.00909437] | 不作为中介比例 |
| 原同集合历史差 T=K_B-K_A | -0.0812528 | 0.0776404 | [-0.162731, 0.000225777] | 约-7.80% |

百分比是FID几何比的变化，不是“生成质量提高了多少百分比”。原同集合历史差重算为-0.0812528，与协议中的核对线索一致；没有借用14对或26对总体的历史优势作分母，也不把D/T解读成中介比例。

| seed | D_A | D_B | P_match |
| --- | ---: | ---: | ---: |
| 55 | -0.0121860 | 0.00636184 | -0.00927393 |
| 56 | -0.0523169 | -0.00339096 | -0.02446295 |
| 59 | 0.0234955 | 0.02350586 | -0.00000520 |
| 60 | -0.0409023 | -0.06979486 | 0.01444630 |
| 61 | -0.0250306 | 0.00438931 | -0.01470994 |
| 62 | -0.0488280 | -0.05295811 | 0.00206506 |

主共同四格集合和两个接收方各自可用配对集合均为全部六seed，无缺失。D_A有一个反方向seed，D_B正负混合。平均P_match略为负且区间跨0，不支持“两边自己的optimizer都更兼容”的确定结论。

X_A_from_B、X_B_from_A的E_512 FID算术均值分别为9.0118、8.6520（对应K为9.2695、8.5024）。互换相较自身对照的变化量级较小；这一观察与完整重启的巨大损伤不同，但不是一个额外设计的联合确认性检验。

## 辅助读出与KID：不能挑显著项替换主要结果

以下FID均使用共同B0；因此不把三block主分析与单block ONLINE的差直接当成读出效应检验。

| 共同B0读出 | M2 Theta_SE：mean [95% CI] | SWAP D_A：mean [95% CI] | SWAP D_B：mean [95% CI] |
| --- | --- | --- | --- |
| E_512 | 1.65052 [-0.28412, 3.58517] | -0.025706 [-0.054188, 0.002776] | -0.014333 [-0.054318, 0.025652] |
| E_KEEP | 1.63796 [-0.28452, 3.56045] | -0.023828 [-0.052397, 0.004741] | -0.013200 [-0.054077, 0.027677] |
| ONLINE | 0.48579 [-0.95833, 1.92992] | 0.001951 [-0.122032, 0.125934] | 0.016527 [-0.094556, 0.127610] |

所有这些FID区间均跨0。SWAP的ONLINE点估计方向不再偏向B，故不能将EMA上的方向泛化为在线模型普遍来源优势，也不能凭“这里显著、那里不显著”声称读出存在显著差异。

E_512三block原始KID差：M2 Theta_SE=0.128912，区间[-0.0869545,0.344779]；SWAP D_A=-0.000214688，区间[-0.000421152,-0.00000822319]；D_B=-0.0000901797，区间[-0.000415256,0.000234897]。A接收方KID的单项名义区间略低于0，是需要报告的辅助结果，但共享同批特征、未校正多重比较，不能替换未解析的主FID或成为“独立确认”。全部KID组件与逐seed数据见配对明细和JSON。

## 方法、完整性和解释范围

估计是在各比较所需的完整seed集合内先计算配对差，然后计算`mean ± t_(0.975,n−1) × SD/√n`。所有主要、辅助和交集集合均n=6；无插补，无删除大FID，无把generation block充当新样本。SWAP两项区间是各自的名义95%，不是联合95%覆盖保证。

操作和数据来源遵循[冻结协议](../STATE_INTERVENTIONS_PROTOCOL.md)。数值训练、有限输入对齐、own-state回放、32与16+恢复+16轨迹检查独立于质量值；24条新训练均运行至8000 attempts。没有因本轮质量差而换seed、改精度、加skip容忍或补训。

原seed55/56的R_B@768源状态曾因合法旧终态复核记录缺少exit_code而在导出前停下；核对旧runner后只兼容该PASS/8000旧格式，保留原错误，未改源。后续评估按空闲卡分流，旧队列的调度占位停止不计为科学失败。最终以唯一实际槽位回执统计，不按队列退出文字删样本。

本报告的推断仅限这个已观察完成条件子集和指定完整RAdam操作。不能推断原总体失败率下降、唯一记忆存储、所有历史收益的自然中介比例，或已识别普遍训练关键期。严重质量损伤与数值非有限失败也不是同一指标。
