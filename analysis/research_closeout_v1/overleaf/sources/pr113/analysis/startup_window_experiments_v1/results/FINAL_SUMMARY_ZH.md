# ECT：q128四臂与q256延后窗口最终汇总

本轮规范矩阵 **40条训练、120个新增评估块全部完成**，另精确复用48个旧对照块。两组完整共同集合均n=8；全部训练、评估与恢复资产最终保存在ECT服务器，规范资产共2,574个文件、约305.69 GB逻辑数据；另有已隔离并校验的重复执行审计。

主要结论是：**q256既有富集队列中，早期窗口优于延后窗口；q128新队列没有支持预设的启动双向效应。** 两组结果分别报告，不作跨q因果交互或唯一机制归因。

## q128：新八种子、四臂

32条新训练、96块固定E_512/FP32/NFE1评估全部通过，seeds301–308四臂完整。

主要对比 S=(C−M)/2：**0.004235，95%配对t区间[-0.034159, 0.042629]，p=0.801741**。S正负方向各4/8。M、C的Holm校正p均为1.0，H的支持性p=0.660248；区间均跨零。这是未获得预期效应证据，不能表述为证明无效或证明等效。

## q256：既有富集八种子、直接窗口比较

8条新增延后窗口训练、24块新增评估全部通过，AA及早期窗口48块精确复用。

延后/早期的几何FID比为 **1.11248**，名义95%区间[1.04378, 1.18571]，双侧 **p=0.005504**，8/8种子早期更低。延后相对早期FID高约11.25%。延后相对AA约-2.11%，但区间跨零（p=0.058167）；TOST没有支持±3%等效。

## 分析边界

每个训练种子先在每臂取三个log-FID50k的均值；没有FID150k，没有把评估块当作独立训练重复。q128的M/C采用预设Holm校正，S为主指标、H为支持性；q256的T为既有富集队列探索性主比较。符号翻转是符号对称假设下的敏感性分析。两组种子队列和q均不同，不能以两组显著性或百分比差异估计q的因果作用。
