# 核验与解释范围

Material Passport：本文件覆盖 `q256_d_restore_vs_hold_v1` 的已执行实验与离线结果核验。数据来自16条新DD后缀和冻结的原DA评估，AA仅为辅助。原环境的公开指标→统计复算已验证为exact JSON一致。

核心实现的37项针对性和旧协议测试，加上3项独立真实结果/归档检查，合计40项在本机及原环境通过。DD连续16步与8+8恢复、旧DA在原PR108与新代码的16步状态比较均通过；16条正式DD均通过原D/旧DA边界直接比对、实际FP16前向、原生D因子与全4000步现存batch/t/base_r字段配对。测试及日志不证明未记录的全程epsilon/dropout指纹或完整历史DA的逐位重放。

冻结统计脚本与数据hash见 recomputation.json。原Python3.11.13/PyTorch2.6.0+cu124/NumPy2.1.2/SciPy1.16.1复算exact；本机较新库最大浮点差约3.6e-14，在1e-12容差内。两者不混称同一数值环境。全部图件由已保存结果生成并进行视觉检查。

固定配对t推断针对seed层log差，依赖有限样本下差值分布的适当性。未用正态性检验选择分析方法、删seed或改为另一种检验。全部逐seed结果公开，seed58的大但有限差值保留。95%区间不是“95%的seed获益”，不显著也不证明等效。

方法与统计误读核查覆盖11/11项：

| 项目 | 本结果的处理 |
|---|---|
| Simpson聚合反转 | 主比较始终同一16组；AA三路径比较始终同一14组，不拼接不同集合均值。 |
| 生态谬误 | 统计与解释单位均为training seed，不把3个generation blocks算作3个seed。 |
| 选择/Berkson偏差 | 说明这是已观察PR108后的固定队列扩展；不声称新seed独立确认。 |
| Collider偏差 | 主16组没有按结果过滤或调整中介变量。 |
| 基率忽略 | 非诊断/筛查研究；同时完整报告16/16训练成功与80/80新槽。 |
| 回归均值 | 非按极端FID选择继续训练；全部固定seeds50–65运行并保留有限极端结果。 |
| 幸存者偏差 | DD没有科学失败；AA原有2个缺失保留，辅助推断限定共同有效集合。 |
| 多重搜索 | 唯一主对比DA−DD；TOST边界预设，其他读出/AA比较仅描述性名义区间。 |
| 分析分岔 | DD训练前固定脚本、终点、blocks和3%边界，未按结果扩展scalar质量臂或改阈值。 |
| 因果过度解释 | 只讨论从同一D@512出发的当前策略对比，不识别唯一早期窗口、最佳切点或optimizer唯一中介。 |
| 反向因果 | 当前策略在DD结果产生前已固定，未按FID修改训练或调度。 |
