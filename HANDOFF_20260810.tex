\begin{abstract}
本报告总结 2026-08-10 围绕 ICLR 2027 战略的实测工作。核心结论:通过一系列
\emph{实测}实验,把方案的生死判断钉死——非标量梯度残差存在、有结构、状态条件、
普遍、\emph{良性},但\emph{附庸于标量 gap}。因此"机制+方法"与"诊断信号"两条
升级路径均被证伪,论文最终定位为 \emph{workshop 级诚实负结果},不投 ICLR 主会。
\end{abstract}

\section{诊断规划(来自 ICLR2027\_STRATEGY)}
\label{sec:plan}

\subsection{诊断论文的定位与主张}
诊断论文(`docs/ICLR2027\_DIAGNOSIS\_PAPER`)主张:
\begin{quote}
非标量梯度内容在少步训练中系统性存在、有结构、状态条件、普遍、\emph{良性}——
标量 moment-memory 恒等式($h{=}1.001$)被实测($h{=}0.837$)证伪。
\end{quote}
此点此前未被 2025--26 标量 scale-invariance 文献覆盖($\beta_1{=}\beta_2$、
Adam-atan2、DeVA 均只分析标量/全局缩放)。

\subsection{诊断规划的边界(P1 附庸性 + Arm C + 双级未来预测)}
四重实测证据一致指向残差是真实但无后果的现象:
\begin{itemize}
  \item \textbf{P1 附庸性:}偏相关 $\approx 0$,残差附庸于标量 gap
  \item \textbf{Arm C scale-matched control:}$g{=}1.3$ 改善被 scale-match 消除
        84--100\%(质量改善大部分是平凡 LR 重缩放)
  \item \textbf{未来预测(梯度级):}早期 $R_{\mathrm{grad}}$ 跨 seed 近恒定,不预测
        未来 FID(阴性)
  \item \textbf{未来预测(优化器级):}早期 $R_{\mathrm{opt}}$ 跨 seed 近恒定,不预测
        未来 FID(阴性;机制存在但无质量后果)
\end{itemize}
因此:
\begin{itemize}
  \item \textbf{不声称}残差是质量诊断信号(被 P1 + 双级未来预测证伪)
  \item \textbf{不声称}残差有害或可修正(被 $g{=}1.3$ 赢 FID + Arm C 证伪)
  \item \textbf{不投} ICLR 主会(诊断信号论题不成立)
\end{itemize}
\textbf{Go/No-Go 定论:No-Go for ICLR 主会机制论题。} 你论题前 3 环成立,最后一环
Performance 在梯度级与优化器级均不成立。诚实的 workshop 级结构刻画是最终可发表资产。
